# 호크마 학생용 실행 설명서와 구성도

이 문서는 `on-client` 프로젝트의 현재 파일을 기준으로 실행 위치와 명령을 안내합니다. 앱의 표시 이름은 포털·안내에 쓰는 **호크마**이며, 프로젝트의 실행 파일명과 폴더명은 바꾸지 않습니다. 이 문서는 새 학생 문서이며 기존 `README.md`와 문서를 대체하지 않습니다.

## 1. 목적과 지원 범위

직원이 본인의 로그인·기기 상태, 업무 앱 접근 판정, 최근 접속 기록과 보안 경보를 확인하는 보안 Agent의 학생 작업본입니다. AI 설명은 기록을 이해하기 위한 참고 정보이며, 설명이나 조치 제안만으로 보안 조치가 실행되지는 않습니다.

기본 실행은 기존 접근 제어·XDR 시스템에 연결되지 않은 상태일 수 있습니다. `demo` 실행은 로컬 예제 자료를 보여 주며 실제 계정·시스템 연결을 증명하지 않습니다. 연결 정보나 자격 설정을 추측해 추가하지 마세요.

## 2. 필요 프로그램 및 확인 범위

| 항목 | 프로젝트에서 확인한 기준 | 이 문서를 작성하며 실제 설치·실행을 확인했는가 |
|---|---|---|
| Node.js | `package.json`의 `engines.node`는 `24.19.0` | 아니요. PC에 설치된 실제 버전은 미확인 |
| PowerShell | Windows 실행 스크립트 `tools/start-alekov.ps1` 사용 | 실제 PowerShell 버전은 미확인 |
| 브라우저 | 같은 PC에서 `http://127.0.0.1:5189` 열기 | 브라우저 종류·버전 및 실행은 미확인 |
| npm 패키지 | `package.json`에 외부 `dependencies`가 선언되어 있지 않음 | 설치 명령은 실행하지 않음 |
| 잠금 파일 | 확인한 프로젝트 파일 목록에서 `package-lock.json`은 보이지 않음 | 별도 파일 검색 명령은 실행하지 않음 |

Node.js `24.19.0`은 프로젝트가 선언한 기준이지, 이 PC에 설치된 버전을 확인했다는 뜻은 아닙니다. `npm install`은 이 안내의 필수 실행 절차가 아닙니다. `npm` PowerShell 스크립트가 실행 정책에 막히면 `npm` 대신 `npm.cmd`를 사용합니다.

## 3. 폴더 구조와 코드 경계

```text
on-client/
├─ package.json                  # start, demo, check 스크립트 및 Node.js 기준
├─ public/                       # 제공된 브라우저 화면과 정적 파일
├─ src/
│  ├─ server.mjs                 # 로컬 앱 서버
│  ├─ engine.mjs                 # 기본/예제 엔진 선택 경계
│  ├─ engine/                    # 엔진 연결 모듈
│  ├─ ai/                        # AI 연결·서비스 모듈
│  └─ vulnerabilities/           # 패키지 취약점 관련 모듈
├─ student/
│  ├─ extension.mjs              # 단계별 학생 화면 구현
│  └─ engine-adapter.mjs         # 엔진 어댑터 경계
├─ tools/
│  └─ start-alekov.ps1           # Windows 실행 스크립트
└─ docs/                         # 과제·학생 안내 문서
```

`public/`와 `src/`는 기본 제공 코드 경계입니다. 단계 안내가 지정하지 않은 파일을 임의로 수정하지 마세요. 학생 화면의 단계별 구현은 `student/extension.mjs`에 있습니다. `student/engine-adapter.mjs`는 서버 엔진 연결 경계이며, 실제 서버 연결이 준비됐다고 이 파일만으로 단정할 수 없습니다.

## 4. 실행·종료·재실행

### 기본 실행

1. 기존 작업 파일은 옮기거나 삭제하지 않습니다. 새 PowerShell 창을 열고 프로젝트 폴더 `on-client`로 이동합니다. 예를 들어 파일 탐색기에서 `on-client` 폴더를 연 뒤 주소 표시줄에 `powershell`을 입력해 그 위치에서 열 수 있습니다.
2. PowerShell에서 현재 위치가 `on-client`인지 확인합니다.

   ```powershell
   Get-Location
   ```

3. 아래 명령으로 실행합니다.

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
   ```

4. 실행을 유지하는 PowerShell 창을 닫지 말고 브라우저에서 다음 주소를 엽니다.

   ```text
   http://127.0.0.1:5189
   ```

**정상 시작 신호:** 서버가 실행 중인 동안 브라우저에서 위 주소의 앱 화면이 열립니다. 이 문서에서 특정 콘솔 로그 문구를 확인하지는 않았으므로, 고정된 “Ready” 문구가 출력된다고 가정하지 않습니다.

### 예제 자료로 실행

기본 서버가 이미 실행 중이면 먼저 그 창에서 `Ctrl+C`로 종료합니다. `on-client` 폴더의 새 PowerShell 창에서 다음 명령을 실행합니다.

```powershell
npm.cmd run demo
```

이 명령은 `package.json`의 `demo` 스크립트(`node src/server.mjs --demo`)를 사용합니다. 브라우저 주소는 `http://127.0.0.1:5189`입니다. 화면의 예제 자료는 실제 서버 판정이나 실제 사용자 자료가 아닙니다.

### 문법 검사

`on-client` 폴더에서 실행합니다.

```powershell
npm.cmd run check
```

현재 `package.json`에서 이 검사는 `student/extension.mjs`에 대해 `node --check`를 실행합니다. 문법 확인이며 브라우저 통합 동작이나 ALEPH 단계 판정을 검사하지 않습니다. 이 설명서를 작성하면서 명령을 실제 실행하지 않았습니다.

### 종료와 재실행

서버를 실행한 PowerShell 창에서 `Ctrl+C`를 눌러 종료합니다. 다시 실행할 때는 기본 실행 또는 예제 실행 명령 중 하나를 같은 `on-client` 폴더에서 다시 실행합니다. 이미 서버가 실행 중이면 동일 주소에서 서버를 하나 더 시작하지 마세요.

## 5. 글로 쓴 시스템 구성도

```text
사용자 브라우저
   │ HTTP: http://127.0.0.1:5189 (이 PC의 loopback 주소)
   ▼
로컬 앱 서버: src/server.mjs
   ├── 화면 파일 제공: public/
   ├── 학생 표시 코드: student/extension.mjs
   └── 엔진 연결 경계: student/engine-adapter.mjs 및 src/engine.mjs
          ├── 기본 실행: 연결 없음/미연결 상태를 표시할 수 있음
          ├── 예제 실행: 로컬 예제 엔진 자료 사용 (실제 시스템 연결 아님)
          └── 연결 실행: 접근 제어·XDR 시스템이 별도 승인된 설정으로
                         실제 연결된 경우에만 해당 시스템의 응답을 사용

AI 설명이 활성화된 경우:
로컬 앱 서버 → AI 연결 모듈 → 승인·구성된 AI 게이트웨이
```

화살표는 구성 요소 사이의 논리적 데이터 흐름입니다. 위 주소 외에 이 문서는 서버 주소, AI 게이트웨이 주소, 자격 정보 또는 연결 성공을 주장하지 않습니다. 기본 실행에서 외부 시스템이 연결된 것으로 간주하지 마세요. 브라우저는 loopback 앱 주소에 접속하고, 실제 접근 제어·XDR 및 AI 연결은 서버 측 구성과 권한에 달려 있습니다.

## 6. 학생 구현·제공 코드·확인 상태

| 영역 | 파일·함수 | 역할 | 확인 상태 |
|---|---|---|---|
| 학생 신원 표시 | `student/extension.mjs` — `renderIdentity` | 사용자·기기·세션 표시 | 코드 경계는 단계 안내 기준. 이 문서 작성 중 브라우저 재실행은 안 함 |
| 접근 판정 표시 | 같은 파일 — `renderDecision` | 대기·판정·요청 실패 표시 | 실제 업무 앱 서버 판정은 확인하지 않음 |
| 기록과 상세 | 같은 파일 — `renderEvents` | 기록 목록·필터·기록 상세 | 이전 대화에서 사용자가 화면 확인을 보고했으나, 이번 문서 작성 중 독립 재검증은 안 함 |
| 상태·알림 | 같은 파일 — `renderStatus` | 기기·세션 상태, 알림·도움정보 표시 | 도움정보 예시는 사용자가 공유했음. 버튼 동작은 이번에 실행하지 않음 |
| AI 설명·조치 상태 | 같은 파일 — `renderExplanation`, `renderAction` | 근거 기반 설명과 처리 상태 표시 | 실제 AI 요청·조치 실행은 확인하지 않음 |
| 기본 UI·서버 | `public/`, `src/` | 화면 틀, 서버, 엔진 및 서비스 경계 | 기본 제공 코드. 운영 연결 성공으로 간주하지 않음 |
| 실행 | `tools/start-alekov.ps1`, `package.json` | 로컬 서버 시작 및 스크립트 정의 | 파일·스크립트 이름과 선언은 대조했으나 이번 문서 작성 중 실행하지 않음 |

이 표는 공식 판정이나 기능 통과 보고서가 아닙니다. 실제 화면에서 확인하지 않은 기능은 확인했다고 기록하지 않습니다.

## 7. 오류별 확인 순서

| 증상 | 먼저 확인할 것 | 이 문서에서 안내할 수 있는 범위 |
|---|---|---|
| 브라우저에서 앱이 열리지 않음 | 서버를 실행한 PowerShell 창이 남아 있는지, 작업 위치가 `on-client`인지, 주소가 `http://127.0.0.1:5189`인지 확인 | 이 문서 작성 중 서버를 시작해 원인을 재현하지 않음. 계속되면 실제 오류 문구를 기준으로 공식 프로젝트 안내를 확인 |
| 업무 앱 목록에서 연결 어댑터 오류·연결 없음 표시 | 기본 실행이 미연결일 수 있음을 확인. 화면 모양 확인 목적이면 예제 실행 사용 | 예제 실행은 실제 판정을 제공하지 않음. 설정 파일·서버 주소를 추측해 만들지 않음 |
| 예제 자료가 나타남 | 화면이 `demo` 모드인지 확인 | 이는 합성/예제 자료이며 실제 계정·서버 결과가 아님 |
| PowerShell에서 `npm.ps1` 실행이 차단됨 | 검사 명령에는 `npm.cmd run check` 사용 | 이 우회 명령은 프로젝트 검사 스크립트를 실행하기 위한 것이며, 실행 정책 변경을 요구하지 않음 |
| 목록이 비어 있거나 조회 실패 | 화면의 빈 상태와 오류 안내를 구분하고 상태 메시지 확인 | 테스트 목적으로 장애나 다른 사용자를 만들지 않음. 재시도는 화면의 사용자가 누르는 동작만 사용 |

연결 설정이나 자격 정보가 안내되지 않았다면 새 설정을 만들거나 임의의 값으로 채우지 않습니다. 오류가 계속되면 민감한 값을 가린 오류 문구와 발생 시각·반 이름을 담당자에게 전달합니다. 비밀번호·토큰·API 키는 채팅이나 문서에 붙여 넣지 않습니다.

## 8. 실행 전후 직접 확인 목록

- 새 PowerShell 창의 작업 위치가 `on-client`인지 확인합니다.
- 문서의 명령을 그대로 실행하고 브라우저에서 `http://127.0.0.1:5189`을 엽니다.
- 기본 실행과 `demo` 실행을 구분합니다. 예제 자료를 실제 연결 결과라고 기록하지 않습니다.
- 종료는 실행 중인 창에서 `Ctrl+C`로 하고, 재실행은 같은 작업 위치에서 합니다.
- 실제 설치 버전, 실제 서버 연결, 빈 목록·실패 상태, AI 응답 및 운영 조치 효과는 확인하지 않았다면 미확인으로 남깁니다.

## 9. 확인하지 않은 사항

이 설명서를 작성하는 과정에서는 PowerShell, Node.js, 브라우저 또는 서버를 실행하지 않았습니다. 따라서 설치된 Node.js·PowerShell·브라우저 버전, 실제 시작 신호, 실제 화면, 실제 서버·XDR·AI 게이트웨이 연결, 오류 복구 동작은 미확인입니다. 공식 단계 판정과 통과 여부도 이 문서로 확인되지 않습니다. 문서의 명령은 읽은 `package.json`과 프로젝트 안내를 기준으로 적었으며, 다른 PC에서 실행 성공을 보증하지 않습니다.
